# Navigation pkg

Mensajes del paquete `navigation_pkg` de **Robomesh** necesario para la recepcion de detecciones de personas en la gui

## User.msg

El mensaje contiene la siguiente extructura

|  Nombre |  Tipo |           Descripcion           |
|---------|-------|---------------------------------|
|detection| int32 |Numero de detecciones de personas|
|    x    |float64|          Posicion en x          |
|    y    |float64|          Posicion en y          |
|    z    |float64|          Posicion en z          |
